NEXORA AI - SIMPLE SETUP

1. Rename .env.example to .env
2. Open .env and paste your Telegram bot token and Gemini API key
3. Open a terminal inside this folder
4. Install the packages:

   py -m pip install -r requirements.txt

5. Start the bot:

   py main.py

Your bot includes:
- AI Manager
- Autonomous CFO
- Content Creator
- Learning Center
- Brand Manager
- Business Planner
- User conversation memory
- Clear-memory button

Important:
Use Python 3.11, 3.12, or 3.13 for the smoothest setup.
Never upload your real .env file publicly.
